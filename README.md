# Market Scout Mentor

AI skill that searches and filters for value stocks and crypto using gated fair-value equations. Builds ranked survivor lists, then opens target cards only for names you approve.

## Install (standalone)
1. Open [`Market-Scout-Mentor.md`](Market-Scout-Mentor.md).  
2. Copy the entire file.  
3. Paste into your AI as a system prompt, custom instructions, project knowledge, or skill file (Claude Projects, Cursor, Grok, etc.).

## What it does
- Asks bullish/bearish, style (swing / long hold / day trade), and size sleeve.  
- Runs sequential gates (dip, profit path, entry cut).  
- Computes fair-value price (FVP) and modified fair-value price (MFVP) with explicit modifiers.  
- Hands you a survivor table; you pick what gets a full target card.
